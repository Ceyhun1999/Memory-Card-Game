# Memory Card Game

Игра на память: открывайте карточки и находите пары одинаковых иконок.

**[Играть онлайн →](https://ceyhun1999.github.io/Memory-Card-Game/)**

<p align="center"><img src="screenshots/game.png" width="520" alt="Memory Card Game"></p>

## Как играть

1. На 20 секунд все карточки открыты — запомните расположение
2. Затем они закрываются; открывайте по две карточки подряд
3. Совпали — пара остаётся открытой, нет — карточки закрываются
4. Три ошибки — вы проиграли

## Структура

```
├── index.htm
├── style.css
├── javascript.js   # таймер, раскладка карточек, проверка пар
└── img/            # иконки соцсетей
```

## Запуск

Игра работает без сборки. Откройте `index.htm` в браузере или поднимите локальный сервер:

```bash
python3 -m http.server 8000
```

и перейдите на http://localhost:8000.
